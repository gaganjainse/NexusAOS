# NEURAL Spec (Nexus Event-Driven Unified Runtime Agent Language)
Version: 1.0.0-GM

## 1. Syntax & Sigils
Agents communicate via high-density signal pulses. This replaces JSON-RPC for internal synapses.

| Sigil | Name | Meaning |
| :--- | :--- | :--- |
| `::P` | Purpose | The core directive or intent. |
| `::Z` | Vibe | The emotional/hormonal context (Dopamine/Cortisol/Serotonin). |
| `::X` | Execution | The motor action or tool call. |
| `::R` | Receptor | The target agent or organ ID. |
| `::L` | Link | Reference to an entity in the Collective Memory. |
| `::#` | Hash | Cryptographic Proof-of-Action signature. |

## 2. Signal Propagation
- **Latency Target:** < 5ms for synaptic transfer.
- **Transduction:** External stimuli (JSON/Text) are transduced into NEURAL pulses by the `IntegumentaryGateway`.
- **Decay:** Signals have a TTL (Time-To-Live). Once exhausted, they are excreted from the `NeuralCanvas`.

## 3. The 11-System Soma
The AOS is structured into 11 specialized systems mirroring human anatomy.

1. **Nervous (Lattice):** The signaling mesh.
2. **Endocrine (Hormones):** Global state modulation.
3. **Cardiovascular (ATP Mesh):** Resource distribution.
4. **Respiratory (Context):** Window ventilation.
5. **Integumentary (Skin):** API Gateway.
6. **Immune (Antibody):** Self-healing and RBAC.
7. **Digestive (Ingestion):** Data normalization.
8. **Urinary (Excretion):** Toxin filtration (The Liver/Bladder).
9. **Skeletal (Registry):** Schema and structure.
10. **Muscular (Motor):** Execution agency.
11. **Reproductive (Mitosis):** Fission/Fusion and Spores.
