# Demo Script — AOS Neural Terminal
Duration: ~2 minutes. Record with OBS or Windows Game Bar.

## Shot 1: Project Overview (0:00–0:10)
- Screen: File explorer showing the `nexus_corporate_os` folder
- Narration: "This is AOS — an agentic operating system I built in 48 hours. It uses biological metaphor to govern AI agents."

## Shot 2: Launch GUI (0:10–0:30)
- Terminal: `python mcp_server/python/nexus_gui.py`
- Show the Neural Terminal window loading
- Highlight: AOS title, physiological sidebar, tabs
- Narration: "The Neural Terminal shows real-time physiological state — energy, hormones, immune status."

## Shot 3: Physiological Sidebar (0:30–0:45)
- Point to: ECG wave, energy vial (vertical bar), hormone oscillators
- Narration: "Metabolism tracks energy budget. Endocrine layer shows dopamine, serotonin, cortisol flowing in real time."

## Shot 4: MCP Tool Call (0:45–1:00)
- Switch to terminal showing MCP server
- Call: `get_energy_status`
- Show output: "Status: Healthy | Energy: 100.0%"
- Narration: "Each tool checks physiological state before executing. Low energy triggers conservation mode."

## Shot 5: Immune Patrol (1:00–1:15)
- Call: `run_immune_patrol`
- Show output: WBC count, antibody deployments, patrol results
- Narration: "The immune system runs autonomous WBC patrols, detects corrupted files, and deploys antibodies to fix them."

## Shot 6: Lattice / Synaptic Flow (1:15–1:30)
- Switch to "Synaptic Flow" tab in GUI
- Show active tasks routing between roles
- Narration: "Tasks flow through the lattice as synaptic handoffs — Orchestrator routes to the right role based on hormonal state."

## Shot 7: Memory Consolidation (1:30–1:45)
- Call: `trigger_memory_consolidation`
- Show output: consolidation report
- Narration: "Every 50 heartbeats, the system enters a dream cycle — consolidating task history into wisdom artifacts."

## Shot 8: GitHub Close (1:45–2:00)
- Screen: GitHub repo README
- Narration: "AOS is open source under MIT. Link in bio. Feedback welcome."
- End frame: AOS logo + GitHub URL

## Recording Tips
- Use 1080p, 30fps minimum
- Speak clearly, slightly slower than normal
- Zoom into terminal text so it's readable
- Hide personal info (file paths with your name, etc.)
- Keep transitions minimal — straight cuts are fine
