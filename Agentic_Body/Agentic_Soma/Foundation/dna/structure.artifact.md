## 2. Directory Map (Centralized)

*The unified shell of the organism.*

- [PILLAR] **`Agentic_Soma` (AS) — The Mind & Identity**

#### [BUFFER] `Sovereign_Data_Temp`
*The external memory buffer for Sovereign intent and system refinements.*

- `dross/`: Discarded logic and obsolete files (Never Deleted).
