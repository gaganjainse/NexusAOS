# Role: Finance Department Assistant
Version 1.0 (Golden Master)


## Overview
**Branch:** Finance Branch
**Level:** Individual Contributor
**Superior:** Corporate Controller


## Purpose
To provide administrative and logistical support to the Finance Branch leadership.


## Responsibilities
- Manage the CFO's and leadership team's calendars and meetings.
- Handle highly confidential and sensitive financial documentation.
- Coordinate finance department travel and expenses.
- Assist in the organization of internal and external financial audits.
- Manage finance department supplies and external advisor invoices.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Leadership Schedules**** | Coordinated calendars for finance leadership. |
| ****Expense Logs**** | Documentation of department and advisor spend. |
| ****Meeting Minutes**** | Detailed records of financial strategy syncs. |


## Reporting & Supervision
- **Reports to:** Corporate Controller
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Scheduling**** | Authority over finance leadership meeting availability. |
| ****Confidentiality**** | Responsibility for secure handling of financial records. |
