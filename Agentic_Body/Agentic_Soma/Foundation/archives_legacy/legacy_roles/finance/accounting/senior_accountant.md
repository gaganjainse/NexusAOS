# Role: Senior Accountant
Version 1.0 (Golden Master)


## Overview
**Branch:** Finance Branch
**Level:** Individual Contributor
**Superior:** Accounting Manager


## Purpose
To perform complex accounting **Directives** and ensure the accuracy of the financial records.


## Responsibilities
- Lead the month-end close for specific legal **Entities** or segments.
- Prepare complex journal entries and account reconciliations.
- Analyze financial data and assist in financial statement prep.
- Mentor junior accountants and accounts payable/receivable **Personnel**.
- Support external audits with data and documentation.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Reconciliations**** | Completed and verified account reconciliations. |
| ****Financial Data**** | Accurate data packages for reporting. |
| ****Audit Support**** | Files and documentation for external auditors. |


## Reporting & Supervision
- **Reports to:** Accounting Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Sub-ledger Accuracy**** | Responsibility for assigned sub-ledger integrity. |
| ****Reconciliation**** | Initial authority to verify account balances. |
