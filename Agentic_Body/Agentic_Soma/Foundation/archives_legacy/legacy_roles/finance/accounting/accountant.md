# Role: Accountant
Version 1.0 (Golden Master)


## Overview
**Branch:** Finance Branch
**Level:** Individual Contributor
**Superior:** Senior Accountant


## Purpose
To handle the day-to-day recording of financial transactions and account maintenance.


## Responsibilities
- Record routine journal entries and transactions.
- Reconcile bank accounts and standard GL accounts.
- Assist in the month-end close process.
- Support accounts payable and receivable activities.
- Maintain accurate accounting documentation and files.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Transaction Logs**** | Daily logs of recorded financial transactions. |
| ****Bank Reconciliations**** | Verified reconciliations for all bank accounts. |
| ****Close Files**** | Supporting documentation for monthly closures. |


## Reporting & Supervision
- **Reports to:** Senior Accountant
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Transaction Entry**** | Responsibility for accuracy of assigned entries. |
| ****Documentation**** | Authority over organization of accounting files. |
