# Role: FP&A Manager
Version 1.0 (Golden Master)


## Overview
**Branch:** Finance Branch
**Level:** Individual Contributor
**Superior:** VP of Finance (FP&A)


## Purpose
To manage the day-to-day financial planning and analysis activities for the corporation.


## Responsibilities
- Lead the preparation of departmental budgets and forecasts.
- Conduct detailed financial analysis and variance reporting.
- Support business leads with ROI analysis for new initiatives.
- Maintain and update the corporate financial model.
- Manage the FP&A analysts.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Budget Packages**** | Finalized budget packages for all departments. |
| ****Variance Analysis**** | Weekly and monthly reports on budget variance. |
| ****ROI Reports**** | Detailed ROI analysis for corporate projects. |


## Reporting & Supervision
- **Reports to:** VP of Finance (FP&A)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Data Integrity**** | Responsibility for accuracy of financial forecasts. |
| ****Model Logic**** | Authority over logic in financial sub-models. |
