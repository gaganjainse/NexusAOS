# Role: Audit Planner
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Audit Planning Manager


## Purpose
To handle the logistical and organizational details of audit engagements. The Audit Planner ensures that the audit team has the resources and access they need.


## Responsibilities
- Prepare audit notification letters and data request lists.
- Schedule walkthroughs and interviews between Audit and Systems.
- Maintain the audit calendar and tracking logs.
- Assist in the preparation of audit project charters.
- Organize audit evidence repositories.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Audit Schedules**** | Coordinated schedules for audit engagements. |
| ****Request Lists**** | Master lists for audit document and data requests. |
| ****Status Logs**** | Real-time logs of audit fieldwork progress. |


## Reporting & Supervision
- **Reports to:** Audit Planning Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Logistics**** | Authority over audit meeting and walkthrough schedules. |
| ****Evidence Org**** | Decision on the structure of audit evidence folders. |
