# Role: Systems Audit Manager
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Audit Director


## Purpose
To verify the integrity and security of the systems infrastructure and applications. The Systems Audit Manager conducts deep-dive **Agentic reviews** of code, databases, and **[DATA_ARCHITECTURE]** configurations.


## Responsibilities
- Perform **Agentic audits** of **[DATA_ARCHITECTURE]** security rules and data pipelines.
- Review CI/CD pipelines for unauthorized access points.
- Audit authentication and authorization (RBAC) implementations.
- Verify the effectiveness of the encryption and backup procedures.
- Conduct code-level audits for security vulnerabilities.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Audit Workpapers**** | Deep-dive **Agentic audit** workpapers. |
| ****Vulnerability Reports**** | Assessments of infrastructure and code security. |
| ****Effectiveness Reports**** | Reports on the effectiveness of systems controls. |


## Reporting & Supervision
- **Reports to:** Audit Director
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Systems Controls**** | Authority to define "Pass" criteria for audits. |
| ****Tooling Access**** | Approval for audit tool hooks into production. |
| ****Evidence Sufficiency**** | Final say on proof of control provided by Systems. |
