# Role: Quality Auditor
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Quality Audit Manager


## Purpose
To review process adherence and asset quality against internal standards. The Quality Auditor ensures that **"The Sesha OS Way"** is being followed.


## Responsibilities
- Review pull request history for adherence to review standards.
- Audit **Oracle Interface** assets and string files for design system compliance.
- Check project management tools for proper **Directive** documentation.
- Verify that release checklists are fully completed.
- Identify process gaps and recommend improvements.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Workpapers**** | Quality review workpapers and findings. |
| ****Adherence Checklists**** | Checklists verifying process compliance. |
| ****Improvement Proposals**** | Recommendations for closing process gaps. |


## Reporting & Supervision
- **Reports to:** Quality Audit Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Process Verification**** | Authority to confirm correct process execution. |
| ****Asset Review**** | Initial "Pass/Fail" rating for interface assets. |
