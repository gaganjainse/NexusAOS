# Role: Junior Quality Auditor
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Quality Audit Manager


## Purpose
To support process audits and learn the quality standards of the corporation.


## Responsibilities
- Perform routine spot-checks on project documentation.
- Verify that release checklists are signed off.
- Assist in auditing UI assets for consistency.
- Maintain the quality audit tracking logs.
- Draft initial observations for process reviews.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Spot-check Summaries**** | Records of routine documentation and asset checks. |
| ****Quality Logs**** | Updated tracking logs for audit findings. |
| ****Draft Observations**** | Initial draft reports for process quality reviews. |


## Reporting & Supervision
- **Reports to:** Quality Audit Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Observation Accuracy**** | Responsibility for factual correctness of reports. |
