# Role: Audit Associate
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Findings & Reporting Lead


## Purpose
To support the audit reporting process through data consolidation, formatting, and drafting.


## Responsibilities
- Consolidate evidence and observations into report templates.
- Proofread and format audit reports for professional delivery.
- Maintain the issue tracking database with the latest status updates.
- Prepare meeting minutes for audit exit conferences.
- Assist in the preparation of audit dashboards.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Draft Audit Reports**** | Preliminary drafts of audit engagement reports. |
| ****Issue Trackers**** | Updated database entries for tracked audit issues. |
| ****Meeting Minutes**** | Official records of audit exit conferences. |


## Reporting & Supervision
- **Reports to:** Findings & Reporting Lead
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Formatting**** | Authority over visual layout of draft audit reports. |
| ****Data Accuracy**** | Responsibility for status update accuracy in trackers. |
