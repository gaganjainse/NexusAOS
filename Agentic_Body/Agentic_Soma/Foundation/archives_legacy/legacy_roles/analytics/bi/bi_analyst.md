# Role: BI Analyst
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** Business Intelligence Manager


## Purpose
To design and maintain corporate dashboards and provide actionable reports.


## Responsibilities
- Design and implement dashboards in corporate BI tools.
- Write complex **Structured Logic Queries** for data extraction and reporting.
- Perform data validation to ensure reporting accuracy.
- Document report definitions and calculation logic.
- Support **Personnel** in navigating and interpreting BI reports.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****BI Dashboards**** | Functional and interactive business intelligence dashboards. |
| ****Reporting Queries**** | Verified **Structured Logic Queries** for data extraction. |
| ****Report Documentation**** | Documentation on calculation logic and definitions. |


## Reporting & Supervision
- **Reports to:** Business Intelligence Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Viz Implementation**** | Responsibility for dashboard accuracy and clarity. |
| ****Query Logic**** | Authority over structure of reporting queries. |
