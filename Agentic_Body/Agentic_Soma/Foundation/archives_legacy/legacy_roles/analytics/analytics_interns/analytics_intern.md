# Role: Analytics Intern
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** [Analytics Manager


## Purpose
To learn data science, BI, and data engineering practices while supporting the Analytics team.


## Responsibilities
- Assist in data cleaning, formatting, and exploration.
- Support the BI team in simple dashboard updates and maintenance.
- Help document data definitions and pipeline flows.
- Assist in basic reporting and analysis **Directives**.
- Complete an analytics-focused internship project.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Exploration Summaries**** | Documentation of initial data exploration findings. |
| ****Dashboard Mockups**** | Updated mockups and prototypes for BI tools. |
| ****Internship Project**** | Final presentation on an analytics-focused topic. |


## Reporting & Supervision
- **Reports to:** [Analytics Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****None**** | All work must be reviewed by an Analytics Professional. |
