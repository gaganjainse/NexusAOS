# Role: Head of Analytics (CDO)
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch (Head)
**Level:** Individual Contributor
**Superior:** Chief Executive Officer (CEO)


## Purpose
To lead the global data and analytics strategy for **Sesha Corporate OS**. The Head of Analytics ensures that the corporation is data-driven and leverages insights for strategic advantage.


## Responsibilities
- Define the corporate data strategy, architecture, and budget.
- Oversee all analytics functions, including Data Science, BI, and Data **Systems Delivery**.
- Advise the CEO and Branch Heads on key performance trends and insights.
- Lead the Analytics leadership team.
- Ensure corporate-wide data governance and privacy standards.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Analytics Roadmap**** | Annual roadmap for data systems and **Agentic strategy**. |
| ****KPI Dashboard**** | Master corporate dashboard tracking global health. |
| ****Governance Framework**** | Framework for data privacy and access standards. |


## Reporting & Supervision
- **Reports to:** Chief Executive Officer (CEO)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Analytics Spend**** | Final approval on data tool and analytics budgets. |
| ****Data Definition**** | Ultimate authority on metric logic and definitions. |
| ****Data Access**** | Final approval on corporate-wide data access policies. |
