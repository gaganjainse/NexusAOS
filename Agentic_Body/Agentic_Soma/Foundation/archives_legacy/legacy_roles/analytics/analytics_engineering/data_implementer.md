# Role: Data Implementer
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** Data Engineering Manager


## Purpose
To build and maintain the systems pipelines that move and transform corporate data.


## Responsibilities
- Develop and optimize ETL/ELT pipelines.
- Design and implement data schemas in the **[CORE_INFRASTRUCTURE]**.
- Monitor pipeline health and resolve data integration failures.
- Implement data quality checks and monitoring.
- Document data flows and infrastructure.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Data Pipelines**** | Functional and optimized ETL/ELT pipelines. |
| ****Schema Definitions**** | Infrastructure schema definitions for data storage. |
| ****Data Quality Logs**** | Records of data integrity and quality checks. |


## Reporting & Supervision
- **Reports to:** Data Engineering Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Script Logic**** | Responsibility for correctness of data scripts. |
| ****Data Mapping**** | Authority over mapping logic within pipelines. |
