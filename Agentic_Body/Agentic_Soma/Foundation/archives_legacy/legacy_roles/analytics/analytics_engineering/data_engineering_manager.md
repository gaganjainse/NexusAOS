# Role: Data Engineering Manager
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** Head of Business Intelligence (BI)


## Purpose
To manage the data infrastructure and ETL/ELT pipelines that power the analytics branch.


## Responsibilities
- Supervise a team of **Data Implementers**.
- Oversee the architecture and reliability of the data warehouse and lake.
- Manage the end-to-end data integration and transformation processes.
- Ensure data quality and availability across the analytics stack.
- Set standards for data engineering code and architecture.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Architecture Docs**** | Documentation of data pipeline and warehouse logic. |
| ****Lineage Reports**** | Records of data flow and transformation origins. |
| ****Performance Dashboards**** | Monitoring dashboards for pipeline health. |


## Reporting & Supervision
- **Reports to:** Head of Business Intelligence (BI)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Pipeline Logic**** | Final say on systems implementation of ETL/ELT. |
| ****Infrastructure Specs**** | Approval of **[DATA_ARCHITECTURE]** allocations. |
