# Role: Machine Learning Lead
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** VP of Data Science


## Purpose
To lead the engineering and infrastructure side of machine learning. The ML Lead ensures that models are scalable and integrated into the platform.


## Responsibilities
- Lead the ML engineering team and MLOps processes.
- Design and maintain ML pipelines and infrastructure.
- Optimize model latency and resource utilization in production.
- Collaborate with **[CORE_SYSTEM]** Engineering on model APIs.
- Set standards for ML code and deployment.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Pipeline Architecture**** | Architecture design for scalable ML pipelines. |
| ****Monitoring Dashboards**** | Real-time monitoring for deployed models. |
| ****MLOps Process Docs**** | Documentation of machine learning operational rules. |


## Reporting & Supervision
- **Reports to:** VP of Data Science
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****ML Infrastructure**** | Final say on the ML toolchain and environment. |
| ****Production Readiness**** | Authority to sign-off on engineering quality. |
