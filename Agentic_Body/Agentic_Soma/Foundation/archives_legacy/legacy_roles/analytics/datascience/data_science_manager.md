# Role: Data Science Manager
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** VP of Data Science


## Purpose
To manage the daily operations of the data science team and ensure successful **Directive** delivery.


## Responsibilities
- Supervise a team of Data Scientists.
- Oversee the end-to-end data science lifecycle (Discovery to Deployment).
- Ensure data science projects are aligned with business needs.
- Manage data science code repositories and documentation.
- Provide coaching and mentorship to the team.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Directive Status Reports**** | Updates on data science project progress. |
| ****Data Analysis Memos**** | Formal summaries of findings and methodologies. |
| ****Validation Packages**** | Verified packages for model deployment. |


## Reporting & Supervision
- **Reports to:** VP of Data Science
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Research Design**** | Approval of statistical approaches for projects. |
| ****Data Sets**** | Final say on training and test datasets for models. |
