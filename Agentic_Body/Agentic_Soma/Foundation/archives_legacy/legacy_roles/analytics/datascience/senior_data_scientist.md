# Role: Senior Data Scientist
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** Data Science Manager


## Purpose
To lead complex data science projects and develop high-impact predictive models.


## Responsibilities
- Design and implement advanced statistical models and experiments.
- Lead the discovery and feature engineering process for ML projects.
- Conduct deep-dive analysis on complex operational and business problems.
- Mentor junior data scientists and analysts.
- Present findings and implementation recommendations to leadership.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Model Code**** | Final production-ready code and documentation. |
| ****Analysis Reports**** | In-depth reports on complex operational problems. |
| ****Experiment Frameworks**** | Frameworks for testing and validating models. |


## Reporting & Supervision
- **Reports to:** Data Science Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Feature Engineering**** | Authority over variable selection for assigned models. |
| ****Statistical Method**** | Decision on algorithms used for specific **Directives**. |
