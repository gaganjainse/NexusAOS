# Role: Data Scientist
Version 1.0 (Golden Master)


## Overview
**Branch:** Analytics Branch
**Level:** Individual Contributor
**Superior:** Senior Data Scientist


## Purpose
To build data-driven models and perform analysis to solve business problems.


## Responsibilities
- Develop and validate predictive models and statistical analyses.
- Perform data cleaning, transformation, and exploration.
- Visualize and communicate complex data findings.
- Write clean, documented, and reproducible **Agentic Logic**.
- Collaborate with BI and **Systems Delivery** on data requirements.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Model Drafts**** | Initial models and validation reports. |
| ****Exploration Summaries**** | Documentation of data exploration findings. |
| ****Analysis Assets**** | Logic-based assets for operational analysis. |


## Reporting & Supervision
- **Reports to:** Senior Data Scientist
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Analysis Logic**** | Responsibility for statistical correctness of work. |
| ****Visual Presentation**** | Authority over layout of assigned data charts. |
