# Role: Contract Specialist
Version 1.0 (Golden Master)


## Overview
**Branch:** Legal Branch
**Level:** Individual Contributor
**Superior:** Contract Manager


## Purpose
To handle the administrative and **Agentic** aspects of contract drafting and tracking.


## Responsibilities
- Prepare initial drafts of standard contracts using templates.
- Coordinate the signing process.
- Upload and tag executed contracts in the CMS.
- Monitor contract deadlines and send renewal notifications.
- Assist in contract-related data entry and reporting.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Contract Drafts**** | Prepared and formatted initial contract drafts. |
| ****Executed Logs**** | Records of signed and finalized agreements. |
| ****Renewal Reports**** | Weekly reports on upcoming contract expirations. |


## Reporting & Supervision
- **Reports to:** Contract Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Formatting**** | Responsibility for visual layout of contract drafts. |
| ****Data Entry**** | Authority over accuracy of contract metadata tags. |
