# Role: Growth Specialist
Version 1.0 (Golden Master)


## Overview
**Branch:** Marketing Branch
**Level:** Individual Contributor
**Superior:** Performance Marketing Manager


## Purpose
To implement and optimize digital marketing campaigns to drive user growth.


## Responsibilities
- Execute paid ad campaigns across multiple channels.
- Monitor campaign performance and perform daily optimizations.
- Create tracking links and manage UTM parameters.
- Assist in landing page testing and optimization.
- Provide data analysis on user acquisition trends.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Ad Campaigns**** | Optimized and monitored digital ad campaigns. |
| ****Weekly Summaries**** | Performance summaries for all paid channels. |
| ****Tracking Docs**** | Documentation of campaign tracking and parameters. |


## Reporting & Supervision
- **Reports to:** Performance Marketing Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Ad Tweaks**** | Authority to adjust ad copy and targeting. |
| ****Tracking Logic**** | Responsibility for accuracy of campaign tracking. |
