# Role: Events Specialist
Version 1.0 (Golden Master)


## Overview
**Branch:** Marketing Branch
**Level:** Individual Contributor
**Superior:** Events Manager


## Purpose
To execute the logistical details of marketing events and conferences.


## Responsibilities
- Handle event registrations and shipment of materials.
- Coordinate event **Personnel** schedules and requirements.
- Assist in booth setup and teardown at trade shows.
- Manage lead collection devices and initial data entry.
- Support the Events Manager in event communication.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Logistics Checklists**** | Comprehensive lists for event operational readiness. |
| ****Shipment Trackers**** | Logs tracking arrival and return of event assets. |
| ****Staff Schedules**** | Coordinated calendars for event team coverage. |


## Reporting & Supervision
- **Reports to:** Events Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Logistics Details**** | Authority over execution of assigned logistical Directives. |
| ****Lead Data**** | Responsibility for accuracy of collected lead info. |
