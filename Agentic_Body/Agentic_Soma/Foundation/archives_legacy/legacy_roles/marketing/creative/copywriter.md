# Role: Copywriter
Version 1.0 (Golden Master)


## Overview
**Branch:** Marketing Branch
**Level:** Individual Contributor
**Superior:** Copy Chief


## Purpose
To write compelling marketing copy that drives action and maintains the brand voice.


## Responsibilities
- Write copy for digital ads, landing pages, and emails.
- Create social media captions and video scripts.
- Assist in writing long-form content like case studies.
- Proofread and edit marketing materials for accuracy.
- Collaborate with designers to ensure copy/design alignment.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Ad Copy**** | Draft and final copy for digital advertising. |
| ****Scripts**** | Storyboards and scripts for marketing videos. |
| ****Web Content**** | Written blocks for website and landing pages. |


## Reporting & Supervision
- **Reports to:** Copy Chief
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Copy Accuracy**** | Responsibility for grammatical and factual quality. |
| ****Creative Direction**** | Authority over tone within assigned copy **Directives**. |
