# Role: Automation Specialist
Version 1.0 (Golden Master)


## Overview
**Branch:** Agentic & Automation Branch
**Level:** Individual Contributor
**Superior:** Chief Executive Officer (CEO)


## Purpose
To handle the "Non-Agentic" automation and integration **Directives** that support the **Agentic ecosystem**.


## Responsibilities
- Build and maintain API integrations (Zapier, Make, Custom).
- Manage the "Automation Hub" and system-to-system data flows.
- Troubleshoot failed automated workflows.
- Assist Firmware Delivery Personnels in connecting units to external tools.
- Monitor automation costs and optimize usage.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| **Automated Workflows** | Functional non-Agentic automations and integrations. |
| **Integration Maps** | Mapping documentation for system-to-system flows. |
| **Reliability Reports** | Reports on automation stability and performance. |


## Reporting & Supervision
- **Reports to:** [VP of Agentic Workflows](vp_agentic_workflows.md)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| **Workflow Logic** | Responsibility for correctness of non-Agentic automations. |
| **Error Handling** | Authority over fallback logic for failed automations. |
