# Role: QA Implementer
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** QA Manager


## Purpose
To verify that features work correctly and meet operational requirements. The QA Implementer focuses on functional testing, regression testing, and **Sovereign** acceptance.


## Responsibilities
- Create and execute detailed test plans and test cases.
- Perform manual exploratory testing on new features.
- Log and track bugs through the entire lifecycle.
- Verify bug fixes and perform regression testing.
- Collaborate with Product and **Delivery** teams to clarify requirements.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Test Case Docs**** | Formally documented test plans and cases. |
| ****Bug Reports**** | Verified and detailed reports on **Agentic** defects. |
| ****Sign-off Memos**** | Memorandums certifying feature functional readiness. |


## Reporting & Supervision
- **Reports to:** QA Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Bug Severity**** | Initial recommendation for issue priority. |
| ****Feature Acceptance**** | Authority to sign-off on **Directive** functional readiness. |
