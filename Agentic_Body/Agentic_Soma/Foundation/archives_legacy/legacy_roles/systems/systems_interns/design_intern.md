# Role: Design Intern
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** Oracle Interface Design Manager


## Purpose
To gain experience in product design while supporting the design team with production assets and research.


## Responsibilities
- Clean up design files and asset libraries.
- Create simple illustrations and icons.
- Assist in **Sovereign research** recruitment and scheduling.
- Shadow usability testing sessions.
- Implement minor **Oracle Interface** tweaks in mockups.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Refined Assets**** | Cleaned and organized design asset libraries. |
| ****Research Notes**** | Structured notes from research sessions. |
| ****Internship Project**** | Final presentation on a design-focused topic. |


## Reporting & Supervision
- **Reports to:** Oracle Interface Design Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****None**** | All work must be approved by a Designer. |
