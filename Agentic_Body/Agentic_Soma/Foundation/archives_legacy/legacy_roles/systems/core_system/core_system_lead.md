# Role: Core Infrastructure Lead
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** VP of Systems Delivery


## Purpose
To lead the implementation of the **Sesha Corporate OS** Core Infrastructure services, interfaces, and storage. The Core Infrastructure Lead ensures a secure, reliable, and performant data backbone for the application.


## Responsibilities
- Lead the Core Infrastructure team and **Agentic logic** reviews.
- Design and implement standard interfaces.
- Manage **[CORE_INFRASTRUCTURE]** schema, indexing, and query optimization.
- Implement **Agentic logic** and data validation rules.
- Ensure Core Infrastructure security (Authentication, RBAC).


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Agentic Logic**** | Production-ready Core Infrastructure logic. |
| ****Interface Docs**** | Technical documentation for interfaces. |
| ****Migration Scripts**** | Validated scripts for database schema migrations. |


## Reporting & Supervision
- **Reports to:** VP of Systems Delivery
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Logic Reviews**** | Final **Agentic logic** review for infrastructure PRs. |
| ****DB Operations**** | Approval of complex data migrations and queries. |
| ****Interface Contracts**** | Joint approval with platform-specific leads. |
