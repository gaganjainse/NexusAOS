# Role: Documentation Manager
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** VP of Systems Delivery


## Purpose
To ensure that **Sesha Corporate OS** is well-documented for both internal **Personnel** and external **Sovereigns**. The Documentation Manager makes the system understandable and easy to use.


## Responsibilities
- Manage the internal **Personnel** wiki and **Agentic documentation**.
- Oversee the creation of manuals and help guides.
- Ensure **[CORE_INFRASTRUCTURE]** documentation is accurate and up-to-date.
- Coordinate with **Firmware Asset** and **Delivery** teams for release notes.
- Maintain the documentation style guide.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Documentation Site**** | Live site for system and delivery docs. |
| ****Reference Guides**** | Technical reference guides for infrastructure. |
| ****Release Notes**** | Standardized notes for each production deployment. |


## Reporting & Supervision
- **Reports to:** VP of Systems Delivery
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Content Quality**** | Final sign-off on all public-facing documentation. |
| ****Doc Tools**** | Selection of documentation platforms. |
| ****Style Guide**** | Authority over systems terminology and formatting. |
