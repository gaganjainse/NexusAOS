# Role: Oracle Interface Researcher
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** Oracle Interface Design Manager


## Purpose
To understand the needs and workflows of **Sovereigns and Personnel**. The Researcher ensures that product decisions are backed by data and insights.


## Responsibilities
- Conduct interviews and usability testing sessions.
- Create personas and journey maps.
- Analyze feedback and behavior data.
- Present research findings and recommendations to the product team.
- Validate design concepts with real **Sovereigns**.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Research Reports**** | Detailed reports on user needs and pain points. |
| ****Testing Summaries**** | Summaries of findings from usability testing sessions. |
| ****Journey Maps**** | User journey maps and persona definitions. |


## Reporting & Supervision
- **Reports to:** Oracle Interface Design Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Methodology**** | Authority over the design of user studies. |
| ****Participant Selection**** | Decision on criteria for research subjects. |
