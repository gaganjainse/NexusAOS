# Role: Oracle Interface Design Manager
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** [Product Director


## Purpose
To lead the visual and interaction design of the **Sesha Corporate OS** app. The Design Manager ensures a consistent, intuitive, and accessible experience for **Sovereigns and Personnel**.


## Responsibilities
- Lead the design system (tokens, components, patterns).
- Oversee interface designers and their workflows.
- Conduct usability testing and iterate on designs.
- Ensure designs meet accessibility standards.
- Collaborate with platform leads on **Agentic setup**.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Design System Docs**** | Comprehensive documentation of design components. |
| ****High-fidelity Prototypes**** | Verified prototypes for platform setup. |
| ****Sovereign Research Summaries**** | Insights from testing and research sessions. |


## Reporting & Supervision
- **Reports to:** [Product Director
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Visual Identity**** | Final sign-off on brand and UI elements. |
| ****Interface Flow**** | Approval of user journeys and interaction patterns. |
| ****Design System**** | Authority over component library changes. |
