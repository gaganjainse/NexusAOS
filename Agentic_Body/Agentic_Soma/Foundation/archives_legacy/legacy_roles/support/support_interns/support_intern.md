# Role: Support Intern
Version 1.0 (Golden Master)


## Overview
**Branch:** Customer Support Branch
**Level:** Individual Contributor
**Superior:** Support Supervisor


## Purpose
To learn modern customer support and **Agentic setup** practices while supporting the Support team.


## Responsibilities
- Assist in responding to basic product inquiries.
- Support the maintenance of the Help Center and FAQs.
- Help with support data entry and metric reporting.
- Shadow Tier 1 and Tier 2 support interactions.
- Complete a support-focused internship project.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Help Center Updates**** | Updates to public-facing help articles and FAQs. |
| ****Support Data Logs**** | Structured logs of support interactions and metrics. |
| ****Internship Project**** | Final project presentation on a support-focused topic. |


## Reporting & Supervision
- **Reports to:** Support Supervisor
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****None**** | All work must be reviewed by a Support Professional. |
