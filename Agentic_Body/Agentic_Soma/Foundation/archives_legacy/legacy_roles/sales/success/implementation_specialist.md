# Role: Implementation Specialist
Version 1.0 (Golden Master)


## Overview
**Branch:** Sales Branch
**Level:** Individual Contributor
**Superior:** Customer Success Manager (CSM)


## Purpose
To handle the **Agentic** and operational setup of **Sesha Corporate OS** for new customers.


## Responsibilities
- Configure the **Sesha Corporate OS** environment for new core business units.
- Lead the data import and initial configuration phase.
- Conduct **Agentic training** for operational **Personnel** and admins.
- Troubleshoot initial setup issues and ensure a smooth go-live.
- Document customer-specific configurations.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Customer Environments**** | Fully configured and operational customer environments. |
| ****Training Logs**** | Records of initial training sessions for customers. |
| ****Setup Documentation**** | Documentation of customer-specific configurations. |


## Reporting & Supervision
- **Reports to:** Customer Success Manager (CSM)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Config Accuracy**** | Responsibility for correctness of system setup. |
| ****Agentic Sign-off**** | Initial authority to mark setup as "Ready for Go-Live". |
