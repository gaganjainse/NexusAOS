# Role: Internal Infrastructure Implementer
Version 1.0 (Golden Master)


## Overview
**Branch:** Operations Branch
**Level:** Individual Contributor
**Superior:** Internal Infrastructure Lead


## Purpose
To implement and maintain the **Agentic infrastructure** that power the internal corporate network.


## Responsibilities
- Configure and maintain internal routers, switches, and firewalls.
- Manage internal **[CORE_INFRASTRUCTURE]** environments and storage.
- Monitor network performance and troubleshoot connectivity issues.
- Implement internal security patches and updates.
- Support the implementation of internal communication and collaboration tools.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Configuration Logs**** | Accurate logs of all network and firewall changes. |
| ****Uptime Data**** | Real-time and historical network uptime reports. |
| ****Infrastructure Docs**** | Documentation of internal **Agentic architecture**. |


## Reporting & Supervision
- **Reports to:** Internal Infrastructure Lead
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Implementation**** | Responsibility for correctness of assigned **Directives**. |
| ****Alerting Levels**** | Authority over alerting thresholds for owned systems. |
