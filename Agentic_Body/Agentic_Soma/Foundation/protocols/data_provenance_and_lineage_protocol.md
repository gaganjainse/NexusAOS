## The Sovereign Interaction Rule (New Law)
Every prompt from the Sovereign triggers a complete cycle that must be permanently recorded:
1. **Prompt** — The Sovereign's directive is captured exactly.
2. **Thinking** — The reasoning process is saved verbatim.
3. **Output** — The final delivery is recorded truthfully (no deception).
4. **Save** — The full cycle is appended to `Sovereign_Data_Temp/interaction_history.md`.
5. **Commit** — The saved file is staged, committed, and the commit hash is recorded.
6. **Push** — The commit is pushed to the repository (truthfully reported if it fails).

This satisfies Law III (Absolute Honesty / Non-Deception) by making every thought and action permanently verifiable through the execution logs.
