# Changelog

All notable changes to AOS will be documented in this file.

## [0.1.0] — 2026-07-20

### Added
- Initial public release
- 12 integration tests (12/12 passing)
- FastMCP server with ~50 tools
- Neural Terminal GUI (customtkinter)
- 7 physiological layers: Metabolism, Endocrine, Immune, Motor, Memory, Lattice, Fission/Fusion
- Background services: Pulse, Guardian, Senses, Orchestrator, Supervisor
- Physiological gating (cortisol/energy-based tool permissioning)
- Antibody engine with WBC patrol, antibody correction, memory cells
- Cellular engine mapping biological components to AOS runtime
- Vision engine (image analysis)
- Video engine (frame extraction + analysis)
- Fission/Fusion engine (branch splitting and merging)
- Plugin registry with Cursor IDE bridge
