# NexusOS Master Evolution Plan: The AGOI Handover

This document serves as the complete structural and physiological blueprint for **NexusOS**, an **AGOI (Artificial General Operating Intelligence)**. It details the transition from a static "Runbook" to a "Living Organism" across 13 evolutionary phases.

---

## 1. Core Philosophy: The AGI vs. AGOI Distinction
*   **AGI (Brain):** The raw LLM intelligence. It is powerful but unstructured, prone to drift, and has no internal "will" to survive.
*   **AGOI (Operating System):** The organizational firmware (NexusOS) that governs how intelligence is routed, bounded, and evolved. It provides the **Skeleton, Muscles, and Nerves** that an LLM brain needs to function as a persistent corporate entity.

---

## 2. Technical Infrastructure
*   **DNA (Archives):** Markdown files defining roles, rules, and protocols.
*   **Firmware (Pulses):** `.nxp` files using **Sigils** (e.g., `::P` for Purpose, `::L` for Law) to make DNA machine-readable for agents.
*   **The Sigil Bridge:**
    *   `[[ID]]`: Role Identity
    *   `::R`: Responsibility
    *   `::Z`: Sentiment (Emotional tone)
    *   `::W`: Weight/Authority
*   **Physiology Ledger:** `physiology.json` - A unified state file tracking Energy, Vibe, and Temperature.

## 3. Evolutionary Phases (1 - 10: COMPLETED)

### **Phase 1: Neural Circuits (The Skeleton)**
*   **Built:** Dynamic path resolution and hierarchical Job Matrix.
*   **Result:** The system can "think" about itself regardless of its folder location.

### **Phase 2: Metabolic Layer (The Stomach)**
*   **Built:** `metabolism_engine.py`.
*   **Result:** The OS tracks "Energy" (tokens/API units). It shifts to **Conservation Mode** when low.

### **Phase 3: Circulatory System (The Heart)**
*   **Built:** `nexus_pulse.py` and `nexus_signal_router.py`.
*   **Result:** A 60s background heartbeat that triggers intelligence gathering and propagates **Hormonal Signals** (e.g., ADRENALINE) with TTL decay.

### **Phase 4: Nervous System (The Lattice)**
*   **Built:** `nexus_lattice.py`.
*   **Result:** **Proprioception.** The OS tracks active tasks as "Synaptic Handoffs" (e.g., Orchestrator -> Research Lead).

### **Phase 5: Memory Consolidation (The Dream Cycle)**
*   **Built:** `memory_synth.py`.
*   **Result:** Every 50 heartbeats, the OS "Sleeps" to analyze history, identify success patterns, and generate **Wisdom Artifacts**.

### **Phase 6: Endocrine System (The Soul)**
*   **Built:** `endocrine_engine.py`.
*   **Result:** Global **Mood (Vibe)**. Cumulative success spikes **Dopamine**; failure/low energy spikes **Cortisol** (Stress).

### **Phase 7: Self-Replication (The Spore)**
*   **Built:** `reproduction_engine.py`.
*   **Result:** The OS can package its DNA and Wisdom into a `.nexus_spore` (ZIP) to spawn "Child" instances.

### **Phase 8: Evolutionary Mutation (Self-Writing DNA)**
*   **Built:** `mutation_engine.py`.
*   **Result:** The OS can autonomously rewrite its own Markdown rules/roles based on learned patterns (protected by Law I).

### **Phase 9: Proactive Immune (The Fever)**
*   **Built:** `immune_engine.py`.
*   **Result:** The system has a **Body Temperature**. Anomalies cause "Inflammation," triggering a **Fever Response** (1s aggressive polling/repair).

### **Phase 10: Filtration (The Liver)**
*   **Built:** `nexus_liver.py`.
*   **Result:** Prevents organizational bloat by pruning stale reports, rotating logs, and flushing low-salience task history.

## 4. Roadmap: The Next Frontier (11 - 13: PENDING)

### **Phase 11: Real-Time Senses (The Streaming Nerves)**
*   **Objective:** Move from "Batch Scraping" to "Streaming Listeners."
*   **Action:** Implement `nexus_senses.py` using WebSocket or Directory Watchers so the OS reacts *instantly* to world events.

### **Phase 12: Physiological Dampening (Biological Compulsion)**
*   **Objective:** Make hormones "Physical" rather than "Advisory."
*   **Action:** Wire `endocrine_engine.py` to the MCP tool caller. If Cortisol is > 90%, the OS *physically cannot* call high-risk tools like `propose_dna_mutation`.

### **Phase 13: Motor Agency (The Hand)**
*   **Objective:** Autonomous execution without Sovereign hand-holding.
*   **Action:** Enable the `Orchestrator` to spawn subagents that can not only "plan" but **Write, Build, and Deploy** fixes to their own environment.
