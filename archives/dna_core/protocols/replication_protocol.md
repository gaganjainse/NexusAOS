# Document: Replication & Lineage Protocol
Version 1.0 (Golden Master)

## Overview
**Branch:** Core
**Level:** Protocol
**Superior:** Sovereign Proxy (Nexus Omni-Lead)

## Purpose
To enable the **NexusAOS** to autonomously or directedly spawn "Child" instances. This protocol ensures generational continuity while allowing for evolutionary adaptation.

## The Spore
A "Spore" is a serialized snapshot of the system state required for "Birth."
- **DNA (Fixed):** All Markdown files in `archives/dna_core/foundation` and `archives/dna_core/rules`.
- **Wisdom (Inherited):** Consolidated Learning Artifacts from `archives/dna_core/learning`.
- **Logic (Current):** The latest `.nxp` firmware pulses.

## Spawn Conditions
The OS is considered "Mature" and capable of replication when:
1.  **Energy:** >80% (Metabolic abundance).
2.  **Vibe:** Euphoric or Stable (System confidence).
3.  **Wisdom Depth:** At least 3 consolidated patterns (Experience).

## Generational Lineage
- **Parent ID:** The unique hash of the originating OS.
- **Generation:** N+1.
- **Mutation Delta:** A small percentage of logic in the Child instance may be flagged for "Experimental Mutation" to test new operational theories.
