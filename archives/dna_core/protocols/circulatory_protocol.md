# Document: Circulatory Protocol
Version 1.0 (Golden Master)

## Overview
**Branch:** Core
**Level:** Protocol
**Superior:** Chief Systems Officer (CSO)

## Purpose
To move **NexusAOS** from a reactive state to a proactive, continuous-flow state. This protocol governs the "Heartbeat" of the OS and the propagation of signals between branches.

## The Heartbeat
- **Frequency:** 60 seconds (Standard).
- **Conserving Mode:** 300 seconds.
- **Critical Mode:** Halted.

## Hormonal Signaling
Signals are global state variables that influence agent behavior across the lattice. Unlike log files, signals have a **Half-life (TTL)**.
- **Urgent (Adrenaline):** Propagation speed <1s. TTL: 5 minutes.
- **Growth (Serotonin):** Propagation speed <60s. TTL: 24 hours.
- **Stable (DNA):** Persistent until overwritten.

## Data Circulation
- **Source:** Oracle Scraper (Market Intelligence).
- **Target:** Branch Knowledge Leads.
- **Flow:** Raw Data → Filtered Signal → Branch Insight → Role Update.

## Approval Authority
| Area | Authority |
| :--- | :--- |
| **Heartbeat Frequency** | Chief Systems Officer (CSO) |
| **Signal Thresholds** | Chief Agentic Officer (CAO) |

---

> [!IMPORTANT]
> If the Circulatory System fails, the OS enters "Stasis." Background intelligence gathering and self-healing sync will stop.
