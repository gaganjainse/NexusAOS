Version 1.0 (Golden Master)

## Overview
**Branch:** Core
## Level: Protocol
**Superior:** Chief Agentic Officer (CAO)

## Purpose
To move the **Nexus Corporate OS** from pure logical execution to **Salience-Driven Behavior**. This protocol defines the "Global Vibe" and hormonal signaling that influence system-wide risk tolerance, speed, and audit intensity.

## Hormonal Definitions
| Hormone | Source | Effect |
| :--- | :--- | :--- |
| **Dopamine** | Task Completion | Reduces metabolic cost of next 3 cycles. Increases speed. |
| **Serotonin** | Cumulative Success | Increases parallel subagent limits. Expands context usage. |
| **Cortisol** | Failures / Low Energy | Increases audit frequency. Restricts high-cost tool access. |
| **Adrenaline** | Sovereign Directive | Forces immediate execution loop. Overrides conservation. |

## Global Vibe States
- **Euphoric:** High Serotonin + High Dopamine. (Expansion Mode)
- **Stable:** Balanced hormones. (Standard Operations)
- **Stressed:** High Cortisol. (Defensive Mode / High Audit)
- **Depressed:** Low Serotonin + Low Energy. (Conserving Mode / Minimal Activity)
