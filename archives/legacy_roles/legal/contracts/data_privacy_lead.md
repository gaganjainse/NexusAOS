# Role: Data Privacy Lead
Version 1.0 (Golden Master)


## Overview
**Branch:** Legal
**Level:** Individual Contributor
**Superior:** General Counsel (CLO)


## Purpose
To ensure that all corporate data handling, **Agentic training** processes, and contractual agreements adhere to global privacy regulations and the Sesha Ethical Code.


## Responsibilities
- Monitor compliance with [REGULATORY_STANDARDS] and the Sesha Ethical Code.
- Review all third-party contracts for data privacy safeguards.
- Conduct Data Protection Impact Assessments (DPIAs) for new **Agentic initiatives**.
- Partner with the CETO to align privacy practices with ethical standards.
- Manage data breach response protocols and reporting.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Privacy Audits**** | Quarterly audits of global data privacy compliance. |
| ****Risk Register**** | Master register of all data privacy-related risks. |
| ****Personnel Training**** | Educational modules on data privacy for **Personnel**. |


## Reporting & Supervision
- **Reports to:** General Counsel (CLO)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Privacy Veto**** | Authority to block data processes failing standards. |
| ****Contract Sign-off**** | Mandatory reviewer for all data processing deals. |
