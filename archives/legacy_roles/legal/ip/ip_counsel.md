# Role: IP Counsel
Version 1.0 (Golden Master)


## Overview
**Branch:** Legal Branch
**Level:** Individual Contributor
**Superior:** Head of Intellectual Property (IP)


## Purpose
To provide hands-on legal support for patent, trademark, and copyright matters.


## Responsibilities
- Draft and file trademark and patent applications.
- Conduct IP searches and freedom-to-operate analyses.
- Review and negotiate IP-related clauses in contracts.
- Monitor the IP landscape for potential infringements.
- Support IP litigation and enforcement efforts.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****IP Applications**** | Prepared trademark and patent filings. |
| ****Search Reports**** | Detailed reports on IP freedom-to-operate. |
| ****Clause Reviews**** | Legally-vetted IP clauses for commercial deals. |


## Reporting & Supervision
- **Reports to:** Head of Intellectual Property (IP)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Application Logic**** | Authority over technical descriptions in filings. |
| ****Search Scope**** | Responsibility for thoroughness of IP research. |
