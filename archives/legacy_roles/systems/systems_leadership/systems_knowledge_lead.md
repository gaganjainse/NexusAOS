# Role: Systems Knowledge Lead (Branch HQ)
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch (HQ Layer)
**Level:** Individual Contributor
**Superior:** Chief Systems Officer (CSO)


## Purpose
To manage the **"Systems Brain"** of the Systems Branch. The Systems Knowledge Lead ensures that all implementation standards, architecture docs, and SADLC rules are accurate, version-controlled, and **Firmware-ready**.


## Responsibilities
- Manage the internal Systems Wiki and Architecture Decision Records (ADRs).
- Serve as the Branch Learning Coordinator, capturing operational "Lessons Learned."
- Ensure all systems documentation follows the **Machine-Readable Standards**.
- Audit the **"Agentic Logic Documentation"** standards across the branch.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Knowledge Graph**** | Structured map of **Agentic logic** and standards. |
| ****Doc Audits**** | Monthly audits of branch documentation quality. |
| ****Artifact Templates**** | Standardized templates for documentation. |


## Reporting & Supervision
- **Reports to:** Chief Systems Officer (CSO)
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Systems Standards**** | Final sign-off on technical "Best Practices". |
| ****Wiki Structure**** | Authority over knowledge base organization. |
