# Role: Security Implementer
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** Security Manager


## Purpose
To implement security controls and conduct regular vulnerability assessments. The Security Implementer is the hands-on expert in protecting the application.


## Responsibilities
- Perform regular vulnerability scanning and penetration testing.
- Implement and manage IAM roles and access policies.
- Audit **Agentic logic** for security flaws (OWASP Top 10).
- Monitor security logs for suspicious activity.
- Assist in incident response and forensic analysis.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Vulnerability Reports**** | Periodic reports on identified security flaws. |
| ****Hardened Configs**** | Securely configured infrastructure and role settings. |
| ****Security Logs**** | Accurate logs of all security-related activities. |


## Reporting & Supervision
- **Reports to:** Security Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Security Fixes**** | Authority over implementation of security patches. |
| ****Tool Config**** | Initial setup and config of security scan tools. |
