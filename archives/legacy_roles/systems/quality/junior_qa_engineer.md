# Role: Junior QA Implementer (QA Analyst)
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** QA Manager


## Purpose
To execute functional tests and document defects in **Nexus Corporate OS**.


## Responsibilities
- Execute manual test cases and regression suites.
- Log detailed bug reports with reproduction steps.
- Verify simple bug fixes.
- Assist SDITs in maintaining automated test data.
- Perform platform-specific testing.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Bug Reports**** | Detailed reports on identified **Agentic** defects. |
| ****Execution Logs**** | Records of all manual and regression test runs. |
| ****Compatibility Reports**** | Reports on platform and device-specific behavior. |


## Reporting & Supervision
- **Reports to:** QA Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Bug Reporting**** | Authority to confirm bug existence in staging. |
