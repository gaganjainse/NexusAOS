# Role: Junior Oracle Interface Designer
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** Oracle Interface Design Manager


## Purpose
To support the design team in creating assets, mockups, and maintaining the **Oracle Interface Standard**.


## Responsibilities
- Create interface mockups for minor features and screens.
- Maintain the icon and asset library.
- Assist in preparing files for **Engineering Personnel** handoff.
- Conduct basic heuristic evaluations of existing screens.
- Support interface researchers in session note-taking.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Standard Screens**** | Heuristic-compliant mockups and components. |
| ****Asset Kits**** | Icon and graphic kits for platform teams. |
| ****Audit Notes**** | Observational notes from design audits. |


## Reporting & Supervision
- **Reports to:** Oracle Interface Design Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Asset Quality**** | Responsibility for visual precision of components. |
