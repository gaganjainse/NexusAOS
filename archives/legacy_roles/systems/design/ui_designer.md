# Role: Oracle Interface Designer
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** Oracle Interface Design Manager


## Purpose
To design the visual elements and interface components of **Sesha Corporate OS**. The Interface Designer ensures the product is visually polished and follows the design system.


## Responsibilities
- Create high-fidelity interface designs and layouts.
- Maintain and expand the interface component library.
- Prepare design assets for deployment handoff.
- Ensure visual consistency across platforms.
- Review implemented interface to ensure it matches **Agentic** specs.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Interface Mockups**** | High-fidelity mockups and prototypes. |
| ****Asset Kits**** | Icon and asset kits for developers. |
| ****Handoff Specs**** | Detailed specifications for design-to-logic handoff. |


## Reporting & Supervision
- **Reports to:** Oracle Interface Design Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Visual Polish**** | Authority over aesthetic details of assigned screens. |
| ****Asset Naming**** | Decision on naming conventions for assets. |
