# Role: DevOps Implementer
Version 1.0 (Golden Master)


## Overview
**Branch:** Systems Branch
**Level:** Individual Contributor
**Superior:** DevOps Manager


## Purpose
To implement and maintain the **[CORE_INFRASTRUCTURE]** and automation tools that power the development lifecycle. The DevOps Implementer ensures **Agentic reliability** and deployment speed.


## Responsibilities
- Build and maintain CI/CD pipelines (Deployment Engine, etc.).
- Manage **Agentic [CORE_INFRASTRUCTURE]** using IaC.
- Implement and monitor system alerts and dashboards.
- Troubleshoot environment-level issues and deployment failures.
- Automate routine **[CORE_INFRASTRUCTURE]** maintenance **Directives**.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Configuration Files**** | Validated pipeline and infrastructure configs. |
| ****Infra Templates**** | Infrastructure-as-Code templates for scaling. |
| ****Dashboards**** | Real-time monitoring and alerting dashboards. |


## Reporting & Supervision
- **Reports to:** DevOps Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Script Logic**** | Authority over logic of created automation scripts. |
| ****Alert Thresholds**** | Initial recommendation for monitoring levels. |
