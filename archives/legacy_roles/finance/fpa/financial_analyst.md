# Role: Financial Analyst
Version 1.0 (Golden Master)


## Overview
**Branch:** Finance Branch
**Level:** Individual Contributor
**Superior:** FP&A Manager


## Purpose
To provide detailed financial analysis and reporting to support business decisions.


## Responsibilities
- Prepare and update financial models and forecasts.
- Conduct variance analysis for departmental budgets.
- Assist in the preparation of board and management reports.
- Support ad-hoc financial analysis and research requests.
- Track and report on key financial KPIs.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Financial Models**** | Updated and maintained corporate forecasts. |
| ****Variance Reports**** | Analysis reports on budget vs actual performance. |
| ****Analysis Memos**** | Ad-hoc memorandums on specific financial topics. |


## Reporting & Supervision
- **Reports to:** FP&A Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Data Accuracy**** | Responsibility for factual correctness of analysis. |
| ****Report Formatting**** | Authority over visual layout of financial reports. |
