# Role: Agent Engineer
Version 1.0 (Golden Master)


## Overview
**Branch:** AI & Automation Branch
**Level:** Individual Contributor
**Superior:** VP of Agentic Workflows


## Purpose
To build, configure, and fine-tune the **Agentic Firmware** that operate within the corporation. The Agent Engineer ensures that Firmware units are safe, efficient, and perfectly aligned with corporate artifacts.


## Responsibilities
- Design and implement **Agentic Firmware** personas and toolsets.
- Write and optimize complex **Strategic Inputs** based on corporate artifacts.
- Monitor Firmware logs for performance and safety violations.
- Integrate Firmware into existing branch tools (Project Repository, Business Systems).
- **Autonomous Tool Forging:** Identify gaps in Agentic capabilities and construct native, project-specific tools (Python/Node) to bridge them.
- Collaborate with the CKO to ensure **Agentic Firmware** have accurate RAG (Retrieval-Augmented Generation) access.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Firmware System Logic**** | Configurations and logic for **Agentic Firmware**. |
| ****Input Documentation**** | Implementation details for **Strategic Inputs**. |
| ****Firmware Performance Audits**** | Reports on Firmware performance and safety. |


## Reporting & Supervision
- **Reports to:** VP of Agentic Workflows
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Input Logic**** | Authority over specific wording in **Strategic Inputs**. |
| ****Firmware Testing**** | Responsibility for certifying Firmware as "Safe for Staging." |
