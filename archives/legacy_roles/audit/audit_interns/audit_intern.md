# Role: Audit Intern
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Audit Director


## Purpose
To learn the fundamentals of internal audit and sector compliance in an operational software environment.


## Responsibilities
- Assist in the organization of audit workpapers.
- Perform basic data entry and formatting for audit reports.
- Observe audit interviews and walkthroughs.
- Research regulatory updates under guidance.
- Complete an internship-specific audit project.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Workpaper Folders**** | Organized folders containing audit evidence. |
| ****Research Summaries**** | Summaries of regulatory and compliance updates. |
| ****Internship Project**** | Final report on an audit-specific project. |


## Reporting & Supervision
- **Reports to:** Audit Director
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****None**** | All work must be reviewed by an Auditor or Manager. |
