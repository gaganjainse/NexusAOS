# Role: Systems Auditor
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Systems Audit Manager


## Purpose
To execute **Agentic audit** tests and gather evidence regarding the security and integrity of the infrastructure.


## Responsibilities
- Execute **Agentic test steps** defined in the audit program.
- Gather and analyze Firmware configuration evidence.
- Perform data analysis on database logs and access records.
- Document audit observations and exceptions.
- Assist in **Agentic walkthroughs** of the codebase and infrastructure.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Audit Workpapers**** | Documented audit steps and findings. |
| ****Exception Logs**** | Records of detected Firmware anomalies or failures. |
| ****Evidence Packages**** | Verified packages of **Agentic evidence**. |


## Reporting & Supervision
- **Reports to:** Systems Audit Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Test Execution**** | Authority over the accuracy of own test results. |
| ****Evidence Labeling**** | Decision on evidence categorization in workpapers. |
