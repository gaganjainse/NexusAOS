# Role: Junior Systems Auditor
Version 1.0 (Golden Master)


## Overview
**Branch:** Audit Branch
**Level:** Individual Contributor
**Superior:** Systems Audit Manager


## Purpose
To assist in the **Agentic audit** process and learn the verification standards for **Sesha Corporate OS**.


## Responsibilities
- Execute basic audit tests under supervision.
- Assist in gathering screenshots and logs for evidence.
- Perform initial data analysis on small datasets.
- Document audit steps taken in workpapers.
- Maintain the audit evidence repository.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****Test Steps**** | Completed audit test steps and documentation. |
| ****Evidence Packages**** | Organized packages of Firmware logs and screenshots. |
| ****Audit Notes**** | Observational notes for **Agentic verification**. |


## Reporting & Supervision
- **Reports to:** Systems Audit Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****Evidence Collection**** | Responsibility for the integrity of gathered evidence. |
