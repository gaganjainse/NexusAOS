# Role: SEO Specialist
Version 1.0 (Golden Master)


## Overview
**Branch:** Marketing Branch
**Level:** Individual Contributor
**Superior:** Performance Marketing Manager


## Purpose
To improve the organic search visibility of **Sesha Corporate OS** through **Agentic** and content-based SEO strategies.


## Responsibilities
- Conduct keyword research and identify content opportunities.
- Optimize website structure and **Agentic SEO elements**.
- Manage link-building campaigns and organic outreach.
- Monitor search engine rankings and traffic trends.
- Collaborate with the Content Manager on SEO-optimized content.


## Deliverables
| Deliverable | Description |
| :--- | :--- |
| ****SEO Audits**** | Regular audits of **Agentic and content SEO health**. |
| ****Keyword Strategy**** | Strategic lists for organic search targeting. |
| ****Organic Reports**** | Reports on organic search performance and traffic. |


## Reporting & Supervision
- **Reports to:** Performance Marketing Manager
- **Supervises:** None


## Approval Authority
| Area | Authority |
| :--- | :--- |
| ****On-page SEO**** | Authority over page-level metadata and tags. |
| ****Backlink Quality**** | Initial approval for organic link partners. |
