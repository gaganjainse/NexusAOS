# Reading Log: Generative Agents: Interactive Simulacra of Human Behavior
**Source**: https://arxiv.org/abs/2304.03442
**Date**: 2026-07-25

## Summary
Introduces an architecture for agents that can remember, reflect, and plan in a virtual society.

## New Points
1. **Memory Stream**: A persistent, natural language record of *all* agent experiences, allowing for long-term "narrative" consistency.
2. **Reflection Layer**: A cognitive process that periodically synthesizes raw memories into higher-level, abstract reflections (e.g., "I like coffee" becomes "I am a morning person").
3. **Dynamic Retrieval**: Planning actions by retrieving a subset of both raw memories *and* synthesized reflections based on the current context.
4. **Interactive Simulacra**: Agents interacting with each other to produce emergent social behaviors (e.g., planning a party).
