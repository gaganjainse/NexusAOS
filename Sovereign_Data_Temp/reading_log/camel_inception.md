# Reading Log: CAMEL: Communicative Agents for "Mind" Exploration
**Source**: https://arxiv.org/abs/2303.17760
**Date**: 2026-07-25

## Summary
Explores autonomous cooperation through role-playing agents using "Inception Prompting."

## New Points
1. **Inception Prompting**: A technique to initialize agents with specific roles and constraints to maintain human intent *without* constant human intervention during multi-turn dialogues.
2. **Autonomous Cooperation**: Removing the Human-in-the-Loop for task execution by allowing agents to guide each other through communicative exchanges.
