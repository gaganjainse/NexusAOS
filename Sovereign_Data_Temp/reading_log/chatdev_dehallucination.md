# Reading Log: ChatDev: Communicative Agents for Software Development
**Source**: https://arxiv.org/abs/2307.07924
**Date**: 2026-07-25

## Summary
Treats software development as a communicative task using a "Chat Chain" to maintain consistency across design, coding, and testing phases.

## New Points
1. **Communicative Dehallucination**: Using multi-turn dialogues between specialized agents (e.g., Coder and Tester) to cross-check logic and identify hallucinations in natural language before they manifest in code.
2. **Chat Chain Workflow**: A serialized communication paradigm that ensures technical consistency by linking diverse roles (Virtual Employees) through a unified language bridge.
