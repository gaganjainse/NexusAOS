# Reading Log: Agents in Artificial Intelligence (GeeksforGeeks / Rishabh Soft)
**Source**: https://www.geeksforgeeks.org/artificial-intelligence/agents-artificial-intelligence/
**Date**: 2026-07-25

## Summary
Classification of agents based on their decision-making logic.

## New Points
1. **Utility-Based Rationality**: Making decisions not just to reach a goal, but to maximize a "Utility Score" (e.g., performance vs. token cost).
2. **Rational Agent vs. Simple Reflex**: Rational agents maximize expected outcomes using *historical* and current data, whereas reflex agents act only on *current* percepts.
